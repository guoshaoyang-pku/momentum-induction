# Funnel Display Medium

Source: https://github.com/google/fonts/tree/main/ofl/funneldisplay
Upstream: https://github.com/Dicotype/Funnel
License: SIL Open Font License 1.1; see OFL.txt.

FunnelDisplay-Medium.ttf is a static instance of the official variable font at
wght=500 (Medium), generated with fontTools.varLib.instancer with updateFontNames=True.
It is loaded locally by fontspec; no system font installation is needed.
The logo is selectable text, not an image or converted outlines.
